# Style Bridge

Find brands and pieces that fit your style, budget and life — not just the brands you already know. Tell us what you like, add an outfit photo, and we'll search official brand sites and reputable stores for specific products, with a reason for each one.

The app is in the [`style-bridge`](style-bridge) folder. See [style-bridge/README.md](style-bridge/README.md) for how to run it.

**Note for judges:** no OpenAI API key is included in this repository. The site runs without one, but live personalized search needs your own key. Setup takes three steps; see the README linked above.
